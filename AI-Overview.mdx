---
title: Using Datafiniti with AI
description: >-
  Connect AI agents and assistants directly to Datafiniti's product, business,
  property, and people data through the Datafiniti MCP server.
---
Datafiniti's Model Context Protocol (MCP) server lets AI agents and assistants query product, business, property, and people data directly, without glue code or a separate integration. Connect popular AI tools such as ChatGPT, Claude, and Postman to search records and retrieve structured data through natural language.

## Supported AI Tools

<Columns cols="3">
  <Card title="MCP Server" href="/mcp-server" icon="server" horizontal="false">
    Connect any MCP-aware client — Claude, ChatGPT, Codex, Cursor, or an agent framework — to search, count, and download data directly.
  </Card>

  <Card title="Postman" href="/postman" icon="send" horizontal="false">
    Use Datafiniti's MCP server from Postman to test and run queries interactively.
  </Card>

  <Card title="ChatGPT/Codex" href="/chatgpt/codex" icon="message-circle" horizontal="false">
    Connect Datafiniti to ChatGPT or Codex via MCP, tool-calling, or plain conversation. Note: people data is not available through ChatGPT/Codex.
  </Card>

  <Card title="Claude" href="/claude" icon="bot" horizontal="false">
    Connect the MCP server so Claude runs queries directly, or just have a conversation and let Claude build queries for you.
  </Card>

  <Card title="Other LLMs" href="/other-llms" icon="brain-circuit" horizontal="false">
    Use any capable model with Datafiniti — via MCP, tool-calling, or plain conversation — by supplying the endpoint, auth, and query syntax.
  </Card>
</Columns>

## Getting Started

<Callout kind="info" collapsed="false">
  To use Datafiniti with an AI tool, you need an API token from your Datafiniti account. [Open the Datafiniti portal](https://portal.datafiniti.co) to create or retrieve your token, then follow the setup instructions for your chosen AI tool.
</Callout>

Each data type page includes setup instructions, example prompts, and schema references to help AI agents query Datafiniti data accurately.
