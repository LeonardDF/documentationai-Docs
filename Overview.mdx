description: >-

  property, and people data through the Datafiniti MCP server.

Datafiniti's Model Context Protocol (MCP) server lets AI agents and assistants query product, business, property, and people data directly, without glue code or a separate integration. Connect popular AI tools such as ChatGPT, Claude, and Postman to search records and retrieve structured data through natural language.

## Getting Started

<Callout kind="info" collapsed="false">
  To use Datafiniti with an AI tool, you need an API token from your Datafiniti account. [Open the Datafiniti portal](https://app.datafiniti.co) to create or retrieve your token, then follow the setup instructions for your chosen AI tool.
</Callout>

Each data type page includes setup instructions, example prompts, and schema references to help AI agents query Datafiniti data accurately.
