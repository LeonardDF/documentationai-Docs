---
title: Business Data Schema
---
The business data schema below lists all available fields in a business record.  Note that actual business records (most of them) may not contain every field.

# Business Operation Fields

<ParamField body="hours" param-type="nested" required="false" deprecated="false" show-location="false">
  The hours of operation for this business location.

  **Example:**

  ```json
  "hours": [
    {
      "day": "Mon - Fri",
      "dept": "Sales",
      "hour": "11:00 am - 9:00 pm"
    },
    {
      "day": "Sat - Sun",
      "meal": "Brunch",
      "hour": "11:00 am - 10:00 pm"
    }
  ]
  ```
</ParamField>

<ParamField body="isClosed" param-type="boolean" required="false" deprecated="false" show-location="false">
  A `true` or `false` value for whether or not the business location is closed.

  **Example:**

  ```json
  "isClosed": false
  ```
</ParamField>

<ParamField body="languagesSpoken" param-type="text" required="false" deprecated="false" show-location="false">
  A list of the languages spoken at this business.

  **Example:**

  ```json
  "languagesSpoken": [
    "English",
    "Spanish"
  ]
  ```
</ParamField>

<ParamField body="paymentTypes" param-type="text" required="false" deprecated="false" show-location="false">
  A list of payment options accepted by the business.

  **Example:**

  ```json
  "paymentTypes": [
    "American Express",
    "Mastercard",
    "Visa"
  ]
  ```
</ParamField>

<ParamField body="productsOrServices" param-type="text" required="false" deprecated="false" show-location="false">
  A list of products or services offered by this business.

  **Example:**

  ```json
  "productsOrServices": [
    "Food",
    "Catering"
  ]
  ```
</ParamField>

# Classification Fields

<ParamField body="categories" param-type="text" required="false" deprecated="false" show-location="false">
  A list of category keywords used for this business across multiple sources.

  **Example:**

  ```json
  "categories": [
    "Seafood Restaurant",
    "Fish & Seafood Retail",
    "restaurant",
    "thing"
  ]
  ```
</ParamField>

<ParamField body="name" param-type="text" required="false" deprecated="false" show-location="false">
  The business location's name.

  **Example:**

  ```json
  "name": "Pete's Seafood & Sandwich"
  ```
</ParamField>

<ParamField body="primaryCategories" param-type="text" required="false" deprecated="false" show-location="false">
  A list of standardized categories to which this business belongs. Category values can be found [here](/docs/possible-values-for-business-fields).

  **Example:**

  ```json
  "primaryCategories": [
    "Retail"
  ]
  ```
</ParamField>

<ParamField body="sic" param-type="text" required="false" deprecated="false" show-location="false">
  The SIC code for the business. [Learn more about SIC codes](https://en.wikipedia.org/wiki/Standard_Industrial_Classification).

  **Example:**

  ```json
  "sic": "5610"
  ```
</ParamField>

<ParamField body="yearIncorporated" param-type="integer" required="false" deprecated="false" show-location="false">
  The year the business was incorporated.

  **Example:**

  ```json
  "yearIncorporated": 2004
  ```
</ParamField>

<ParamField body="yearOpened" param-type="integer" required="false" deprecated="false" show-location="false">
  The year the business opened.

  **Example:**

  ```json
  "yearOpened": 2005
  ```
</ParamField>

# Contact Fields

</ParamField>

<ParamField body="facebookPageURL" param-type="text" required="false" deprecated="false" show-location="false">

  ```

<ParamField body="faxes" param-type="text" required="false" deprecated="false" show-location="false">

  **Example:**

    "3135619486"

  ```
</ParamField>

<ParamField body="phones" param-type="keyword" required="false" deprecated="false" show-location="false">

  **Example:**

  ```json
  "phones": [

    "6195734102"

  ```

<ParamField body="twitter" param-type="text" required="false" deprecated="false" show-location="false">

<ParamField body="websites" param-type="keyword" required="false" deprecated="false" show-location="false">

</ParamField>

# Firmographic Fields

<ParamField body="numEmployeesMax" param-type="integer" required="false" deprecated="false" show-location="false">
  The upper bound on the number of people employed by this business.
</ParamField>

<ParamField body="numEmployeesMin" param-type="integer" required="false" deprecated="false" show-location="false">
  The lower bound on the number of people possibly employed by this business.
</ParamField>

<ParamField body="people" param-type="nested" required="false" deprecated="false" show-location="false">
  A list of known people associated with or employed by this business.
</ParamField>

<ParamField body="revenueCurrency" param-type="keyword" required="false" deprecated="false" show-location="false">
  The currency associated with the revenue fields.
</ParamField>

<ParamField body="revenueMax" param-type="integer" required="false" deprecated="false" show-location="false">
  The maximum known value of the business' annual revenue.
</ParamField>

<ParamField body="revenueMin" param-type="integer" required="false" deprecated="false" show-location="false">
  The minimum known value of the business' annual revenue.
</ParamField>
