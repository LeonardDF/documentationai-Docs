# Business Data Schema

The business data schema below lists all available fields in a business record.  Note that actual business records (most of them) may not contain every field.

## Business Operation Fields

<ParamField body="hours" param-type="nested" showLocation={false}>
  The hours of operation for this business location.

  **Example:**
  ```json
  "hours": [
    {
      "day": "Mon - Fri",
      "dept": "Sales",
      "hour": "11:00 am - 9:00 pm"
    },
    {
      "day": "Sat - Sun",
      "meal": "Brunch",
      "hour": "11:00 am - 10:00 pm"
    }
  ]
  ```
</ParamField>

<ParamField body="isClosed" param-type="boolean" showLocation={false}>
  A `true` or `false` value for whether or not the business location is closed.

  **Example:**
  ```json
  "isClosed": false
  ```
</ParamField>

<ParamField body="languagesSpoken" param-type="text" showLocation={false}>
  A list of the languages spoken at this business.

  **Example:**
  ```json
  "languagesSpoken": [
    "English",
    "Spanish"
  ]
  ```
</ParamField>

<ParamField body="paymentTypes" param-type="text" showLocation={false}>
  A list of payment options accepted by the business.

  **Example:**
  ```json
  "paymentTypes": [
    "American Express",
    "Mastercard",
    "Visa"
  ]
  ```
</ParamField>

<ParamField body="productsOrServices" param-type="text" showLocation={false}>
  A list of products or services offered by this business.

  **Example:**
  ```json
  "productsOrServices": [
    "Food",
    "Catering"
  ]
  ```
</ParamField>

## Classification Fields

<ParamField body="categories" param-type="text" showLocation={false}>
  A list of category keywords used for this business across multiple sources.

  **Example:**
  ```json
  "categories": [
    "Seafood Restaurant",
    "Fish & Seafood Retail",
    "restaurant",
    "thing"
  ]
  ```
</ParamField>

<ParamField body="name" param-type="text" showLocation={false}>
  The business location's name.

  **Example:**
  ```json
  "name": "Pete's Seafood & Sandwich"
  ```
</ParamField>

<ParamField body="primaryCategories" param-type="text" showLocation={false}>
  A list of standardized categories to which this business belongs. Category values can be found [here](/docs/possible-values-for-business-fields).

  **Example:**
  ```json
  "primaryCategories": [
    "Retail"
  ]
  ```
</ParamField>

<ParamField body="sic" param-type="text" showLocation={false}>
  The SIC code for the business. [Learn more about SIC codes](https://en.wikipedia.org/wiki/Standard_Industrial_Classification).

  **Example:**
  ```json
  "sic": "5610"
  ```
</ParamField>

<ParamField body="yearIncorporated" param-type="integer" showLocation={false}>
  The year the business was incorporated.

  **Example:**
  ```json
  "yearIncorporated": 2004
  ```
</ParamField>

<ParamField body="yearOpened" param-type="integer" showLocation={false}>
  The year the business opened.

  **Example:**
  ```json
  "yearOpened": 2005
  ```
</ParamField>

## Contact Fields

<ParamField body="emails" param-type="text" showLocation={false}>
  A list of emails belonging to the business.

  **Example:**
  ```json
  "emails": [
    "elena@searocketbistro.com"
  ]
  ```
</ParamField>

<ParamField body="facebookPageURL" param-type="text" showLocation={false}>
  A URL pointing to the Facebook page for the business.

  **Example:**
  ```json
  "facebookPageURL": "http://www.facebook.com/pages/Sea-Rocket-Bistro/114213985293774"
  ```
</ParamField>

<ParamField body="faxes" param-type="text" showLocation={false}>
  A list of fax numbers for the business.

  **Example:**
  ```json
  "faxes": [
    "3135619486"
  ]
  ```
</ParamField>

<ParamField body="phones" param-type="keyword" showLocation={false}>
  A list of phone numbers for the business.

  **Example:**
  ```json
  "phones": [
    "6192558940",
    "6195734102"
  ]
  ```
</ParamField>

<ParamField body="twitter" param-type="text" showLocation={false}>
  The twitter username for the business.

  **Example:**
  ```json
  "twitter": "sdpark2park"
  ```
</ParamField>

<ParamField body="websites" param-type="keyword" showLocation={false}>
  A list of websites for the business.

  **Example:**
  ```json
  "websites": [
    "http://www.bostonpetes.com/",
    "http://www.searocketbistro.com"
  ]
  ```
</ParamField>

## Firmographic Fields

<ParamField body="numEmployeesMax" param-type="integer" showLocation={false}>
  The upper bound on the number of people employed by this business.
</ParamField>

<ParamField body="numEmployeesMin" param-type="integer" showLocation={false}>
  The lower bound on the number of people possibly employed by this business.
</ParamField>

<ParamField body="people" param-type="nested" showLocation={false}>
  A list of known people associated with or employed by this business.
</ParamField>

<ParamField body="revenueCurrency" param-type="keyword" showLocation={false}>
  The currency associated with the revenue fields.
</ParamField>

<ParamField body="revenueMax" param-type="integer" showLocation={false}>
  The maximum known value of the business' annual revenue.
</ParamField>

<ParamField body="revenueMin" param-type="integer" showLocation={false}>
  The minimum known value of the business' annual revenue.
</ParamField>

## Geographic Fields

<ParamField body="address" param-type="text" showLocation={false}>
  The physical street address for this business location.
</ParamField>

<ParamField body="city" param-type="text" showLocation={false}>
  The city of this business location.
</ParamField>

<ParamField body="country" param-type="text" showLocation={false}>
  The two-letter country code for the business location's country.
</ParamField>

<ParamField body="geoLocation" param-type="geo_shape" showLocation={false}>
  A location value that stores the latitude and longitude in a format that allows geospatial querying.
</ParamField>

<ParamField body="latitude" param-type="text" showLocation={false}>
  The latitude coordinates for this business location.
</ParamField>

<ParamField body="longitude" param-type="text" showLocation={false}>
  The longitude coordinates for this business location.
</ParamField>

<ParamField body="neighborhoods" param-type="text" showLocation={false}>
  A list of neighborhoods where this business is located.
</ParamField>

<ParamField body="postalCode" param-type="keyword" showLocation={false}>
  The postal or zip code of the business' location.
</ParamField>

<ParamField body="province" param-type="text" showLocation={false}>
  The province or state for this business location.
</ParamField>

## Generic Fields

</ParamField>

<ParamField body="dateUpdated" param-type="date" showLocation={false}>

</ParamField>

<ParamField body="descriptions" param-type="nested" showLocation={false}>
  A list of descriptions for this business from various sources.
</ParamField>

<ParamField body="features" param-type="nested" showLocation={false}>

</ParamField>

<ParamField body="keys" param-type="keyword" showLocation={false}>
  A list of internal Datafiniti identifiers for this business.
</ParamField>

## Hospitality Fields

<ParamField body="numRoom" param-type="integer" showLocation={false}>

</ParamField>

<ParamField body="rooms" param-type="nested" showLocation={false}>

</ParamField>

## Restaurant Fields

<ParamField body="cuisines" param-type="text" showLocation={false}>
  A list of cuisines offered by this business location.
</ParamField>

<ParamField body="menuPageURL" param-type="keyword" showLocation={false}>
  A URL pointing to the menu for the business.
</ParamField>

<ParamField body="menus" param-type="nested" showLocation={false}>

<ParamField body="priceRangeCurrency" param-type="keyword" showLocation={false}>

<ParamField body="priceRangeMin" param-type="float" showLocation={false}>

</ParamField>

## Reviews Fields

<ParamField body="reviews" param-type="nested" showLocation={false}>
  A list of reviews for this business location.
</ParamField>

## SourceURL Fields

<ParamField body="claimed" param-type="keyword" showLocation={false}>
  A list of websites where the business location has been claimed by the business' owner.
</ParamField>

<ParamField body="domains" param-type="domain" showLocation={false}>
  A list of each unique domain found in the `sourceURLs` field.
</ParamField>

<ParamField body="imageURLs" param-type="text" showLocation={false}>
  A list of image URLs associated with this business.
</ParamField>

<ParamField body="sourceURLs" param-type="keyword" showLocation={false}>
  A list of URLs used to generate data for this business location.
</ParamField>
