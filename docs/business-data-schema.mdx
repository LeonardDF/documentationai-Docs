---
title: Business Data Schema
---
The business data schema below lists all available fields in a business record.  Note that actual business records (most of them) may not contain every field.

## Business Operation Fields

<ParamField body="hours" param-type="nested" showLocation={false}>
  The hours of operation for this business location.

  **Example:**

  ```json
  "hours": [
    {
      "day": "Mon - Fri",
      "dept": "Sales",
      "hour": "11:00 am - 9:00 pm"
    },
    {
      "day": "Sat - Sun",
      "meal": "Brunch",
      "hour": "11:00 am - 10:00 pm"
    }
  ]
  ```
</ParamField>

<ParamField body="isClosed" param-type="boolean" showLocation={false}>
  A `true` or `false` value for whether or not the business location is closed.

  **Example:**

  ```json
  "isClosed": false
  ```
</ParamField>

<ParamField body="productsOrServices" param-type="text" showLocation={false}>
  A list of products or services offered by this business.

  **Example:**

  ```json
  "productsOrServices": [
    "Food",
    "Catering"
  ]
  ```
</ParamField>

## Contact Fields

</ParamField>

</ParamField>

  ```json
  "faxes": [
    "3135619486"
  ]
  ```
</ParamField>

<ParamField body="phones" param-type="keyword" showLocation={false}>

  **Example:**

  ```json

  ]
  ```
</ParamField>

<ParamField body="twitter" param-type="text" showLocation={false}>

## Firmographic Fields

<ParamField body="categories" param-type="text" showLocation={false}>
  A list of category keywords used for this business across multiple sources.

  **Example:**

  ```json
  "categories": [
    "Seafood Restaurant",
    "Fish & Seafood Retail",
    "restaurant",
    "thing"
  ]
  ```
</ParamField>

<ParamField body="claimed" param-type="keyword" showLocation={false}>
  A list of websites where the business location has been claimed by the business' owner.

  **Example:**

  ```json
  "claimed": [
    "http://yellowpages.com/",
    "http://foursquare.com/"
  ]
  ```
</ParamField>

<ParamField body="numEmployeesMax" param-type="integer" showLocation={false}>
  The upper bound on the number of people employed by this business.

  **Example:**

  ```json
  "numEmployeesMax": "10"
  ```
</ParamField>

<ParamField body="numEmployeesMin" param-type="integer" showLocation={false}>
  The lower bound on the number of people possibly employed by this business.

  **Example:**

  ```json
  "numEmployeesMin": "5"
  ```
</ParamField>

<ParamField body="people" param-type="nested" showLocation={false}>
  A list of known people associated with or employed by this business.

  **Example:**

  ```json
  "people": [
    {
      "dateSeen": "2014-08-22T03:48:23Z",
      "name": "Cody Jones",
      "title": "Owner"
    },
    {
      "dateSeen": [
        "2014-08-22T03:48:23Z"
      ],
      "name": "Chaseee Ewing",
      "title": "Head Chef"
    }
  ]
  ```
</ParamField>

<ParamField body="primaryCategories" param-type="text" showLocation={false}>
  A list of standardized categories to which this business belongs. Category values can be found [here](/docs/possible-values-for-business-fields).

  **Example:**

  ```json
  "primaryCategories": [
    "Retail"
  ]
  ```
</ParamField>

<ParamField body="revenueCurrency" param-type="keyword" showLocation={false}>
  The currency associated with the revenue fields.

  **Example:**

  ```json
  "revenueCurrency": "USD"
  ```
</ParamField>

<ParamField body="revenueMax" param-type="integer" showLocation={false}>
  The maximum known value of the business' annual revenue.

  **Example:**

  ```json
  "revenueMax": 100000
  ```
</ParamField>

<ParamField body="revenueMin" param-type="integer" showLocation={false}>
  The minimum known value of the business' annual revenue.

  **Example:**

  ```json
  "revenueMin": 30000
  ```
</ParamField>

## Geographic Fields

<ParamField body="address" param-type="text" showLocation={false}>
  The physical street address for this business location.

  **Example:**

  ```json
  "address": "3382 30th St"
  ```
</ParamField>

<ParamField body="city" param-type="text" showLocation={false}>
  The city of this business location.

  **Example:**

  ```json
  "city": "San Diego"
  ```
</ParamField>

<ParamField body="country" param-type="text" showLocation={false}>
  The two-letter country code for the business location's country.

  **Example:**

  ```json
  "country": "US"
  ```
</ParamField>

<ParamField body="geoLocation" param-type="geo_shape" showLocation={false}>
  A location value that stores the latitude and longitude in a format that allows geospatial querying.

  The value is stored as Well-Known Text format, which resembles an `(x, y)` value, i.e. `(longitude latitude)`.

  **Example:**

  ```json
  "geoLocation": "POINT (-119.5094 37.229366)"
  ```
</ParamField>

<ParamField body="latitude" param-type="text" showLocation={false}>
  The latitude coordinates for this business location.

  **Example:**

  ```json
  "latitude": "32.740654"
  ```
</ParamField>

<ParamField body="longitude" param-type="text" showLocation={false}>
  The longitude coordinates for this business location.

  **Example:**

  ```json
  "longitude": "-117.129482"
  ```
</ParamField>

<ParamField body="neighborhoods" param-type="text" showLocation={false}>
  A list of neighborhoods where this business is located. Sometimes an area can belong to multiple neighborhoods, which is why this field is a list.

  **Example:**

  ```json
  "neighborhoods": [
    "North Park, Western San Diego",
    "North Park"
  ]
  ```
</ParamField>

<ParamField body="postalCode" param-type="keyword" showLocation={false}>
  The postal or zip code of the business' location.

  **Example:**

  ```json
  "postalCode": "92014"
  ```
</ParamField>

<ParamField body="province" param-type="text" showLocation={false}>
  The province or state for this business location.

  **Example:**

  ```json
  "province": "CA"
  ```
</ParamField>

## Generic Fields

<ParamField body="dateAdded" param-type="date" showLocation={false}>
  The date this business was first added to the business database.

  **Example:**

  ```json
  "dateAdded": "2016-03-24T09:27:02Z"
  ```
</ParamField>

<ParamField body="dateUpdated" param-type="date" showLocation={false}>
  The most recent date this business was updated or seen by our system.

  **Example:**

  ```json
  "dateUpdated": "2017-03-20T20:45:49Z"
  ```
</ParamField>

<ParamField body="descriptions" param-type="nested" showLocation={false}>
  A list of descriptions for this business from various sources.

  **Example:**

  ```json
  "descriptions": [
    {
      "dateSeen": "2016-06-18T01:17:41Z",
      "sourceURLs": [
        "https://www.zagat.com/r/petes-seafood-and-sandwich-san-diego"
      ],
      "value": "Sizable made-to-order sandwiches, including lobster rolls, meatball Parmesan heroes and a variety of vegetarian options, are served at this East Coast–style sandwich shop nestled in the heart of North Park."
    }
  ]
  ```
</ParamField>

<ParamField body="features" param-type="nested" showLocation={false}>
  A list of features associated with this business location. The feature list can be collected from specific feature sections available on listings for this business. It can also serve as a catch-all field for miscellaneous characteristics of this business that don't make sense to include as top-level fields.

  **Example:**

  ```json
  "features": [
    {
      "key": "attire",
      "value": [
        "Casual Dress"
      ]
    },
    {
      "key": "parking",
      "replace": "true",
      "value": [
        "Street Parking",
        "Valet"
      ]
    }
  ]
  ```
</ParamField>

<ParamField body="keys" param-type="keyword" showLocation={false}>
  A list of internal Datafiniti identifiers for this business. The `keys` field is used to merge raw data from individual sources into the master Datafiniti record. [Learn how this works](/docs/how-business-records-are-merged)

  **Example:**

  ```json
  "keys": [
    "us/ca/sandiego/338230thst/2075732923"
  ]
  ```
</ParamField>

<ParamField body="languagesSpoken" param-type="text" showLocation={false}>
  A list of the languages spoken at this business.

  **Example:**

  ```json
  "languagesSpoken": [
    "English",
    "Spanish"
  ]
  ```
</ParamField>

<ParamField body="name" param-type="text" showLocation={false}>
  The business location's name.

  **Example:**

  ```json
  "name": "Pete's Seafood & Sandwich"
  ```
</ParamField>

<ParamField body="paymentTypes" param-type="text" showLocation={false}>
  A list of payment options accepted by the business.

  **Example:**

  ```json
  "paymentTypes": [
    "American Express",
    "Mastercard",
    "Visa"
  ]
  ```
</ParamField>

<ParamField body="sic" param-type="text" showLocation={false}>
  The SIC code for the business. [Learn more about SIC codes](https://en.wikipedia.org/wiki/Standard_Industrial_Classification).

  **Example:**

  ```json
  "sic": "5610"
  ```
</ParamField>

## Hospitality Fields

<ParamField body="numRoom" param-type="integer" showLocation={false}>
  The number of rooms available at this business. This field typically shows for hotels or other similar businesses.

  **Example:**

  ```json
  "numRoom": 10
  ```
</ParamField>

<ParamField body="rooms" param-type="nested" showLocation={false}>
  A list of room types available at the business' location. This field is typically associated with hotels and other similar businesses.

  **Example:**

  ```json
  "rooms": [
    {
      "amountMin": 90,
      "amountMax": 90,
      "capacity": 3,
      "currency": "USD",
      "dateSeen": [
        "2016-05-04T00:00:00Z"
      ],
      "roomType": "Standard Room"
    },
    {
      "amountMin": 119,
      "amountMax": 119,
      "capacity": 4,
      "currency": "USD",
      "dateSeen": [
        "2016-05-04T00:00:00Z"
      ],
      "roomType": "Superior Room"
    }
  ]
  ```
</ParamField>

## Restaurant Fields

<ParamField body="cuisines" param-type="text" showLocation={false}>
  A list of cuisines offered by this business location. This field will only show for restaurants or other eating locations.

  **Example:**

  ```json
  "cuisines": [
    "Seafood Restaurants",
    "Sandwich Shop",
    "Seafood, Vegetarian / Vegan, Mediterranean"
  ]
  ```
</ParamField>

<ParamField body="menuPageURL" param-type="keyword" showLocation={false}>
  A URL pointing to the menu for the business. This field will only show for restaurants or other eating locations.

  **Example:**

  ```json
  "menuPageURL": "http://www.citysearch.com/profile/menu/648254644"
  ```
</ParamField>

<ParamField body="menus" param-type="nested" showLocation={false}>
  A list of menu items offered by the business. This field will only show for restaurants or other eating locations.

  **Example:**

  ```json
  "menus": [
    {
      "amountMin": 12,
      "amountMax": 12,
      "category": "sample menu",
      "currency": "USD",
      "dateSeen": "2017-03-22T01:03:56Z",
      "name": "Fish Carpaccio",
      "sourceURLs": [
        "http://www.superpages.com/bp/san-diego-ca/petes-seafood-sandwich-L2615943735.htm"
      ]
    },
    {
      "amountMin": 7,
      "amountMax": 7,
      "category": "sample menu",
      "currency": "USD",
      "dateSeen": [
        "2017-03-22T01:03:56Z"
      ],
      "description": "A dense bread pudding recipe served cold with butterscotch sauce",
      "name": "Seasonal Pumpkin Bread Pudding",
      "sourceURLs": [
        "http://www.superpages.com/bp/san-diego-ca/petes-seafood-sandwich-L2615943735.htm"
      ]
    }
  ]
  ```
</ParamField>

<ParamField body="priceRangeCurrency" param-type="keyword" showLocation={false}>
  The currency associated with the price range fields.

  **Example:**

  ```json
  "priceRangeCurrency": "USD"
  ```
</ParamField>

<ParamField body="priceRangeMax" param-type="float" showLocation={false}>
  The upper bound of the business' price range. This field is typically used for retail businesses.

  **Example:**

  ```json
  "priceRangeMax": 40
  ```
</ParamField>

<ParamField body="priceRangeMin" param-type="float" showLocation={false}>
  The lower bound of the business' price range. This field is typically used for retail businesses.

  **Example:**

  ```json
  "priceRangeMin": 25
  ```
</ParamField>

## SourceURL Fields

<ParamField body="domains" param-type="domain" showLocation={false}>
  A list of each unique domain found in the `sourceURLs` field.

  **Example:**

  ```json
  "domains": [
    "www.superpages.com",
    "foursquare.com",
    "www.zagat.com"
  ]
  ```
</ParamField>

<ParamField body="imageURLs" param-type="text" showLocation={false}>
  A list of image URLs associated with this business.

  **Example:**

  ```json
  "imageURLs": [
    "https://irs0.4sqi.net/img/general/200x200/118688231_EmfdW9_8FpBrxsa5WDVektvkubj-XpCW5ln6s6pnClo.jpg",
    "https://irs0.4sqi.net/img/general/200x200/1556291_gjOF8nnudHh_ICSWXoTs75_FxtcKt25nZtwbqjaHtKQ.jpg"
  ]
  ```
</ParamField>

<ParamField body="sourceURLs" param-type="keyword" showLocation={false}>
  A list of URLs used to generate data for this business location.

  **Example:**

  ```json
  "sourceURLs": [
    "http://www.superpages.com/bp/san-diego-ca/petes-seafood-sandwich-L2615943735.htm",
    "https://foursquare.com/v/petes-seafood--sandwich/56391bfacd105fac6c403c63",
    "https://www.zagat.com/r/petes-seafood-and-sandwich-san-diego"
  ]
  ```
</ParamField>
