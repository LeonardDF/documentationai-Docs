---
title: People Data Schema
---
The people data schema below lists all available Fields in a people record.  Note that actual people records may not have every field present.

## Brokers Fields

<ParamField body="currentListingCount" param-type="integer" required="false" deprecated="false" show-location="false">
  The number of active property listings currently associated with the broker.

  **Example:**

  ```json
  "currentListingCount": 5
  ```
</ParamField>

<ParamField body="licenses" param-type="nested" required="false" deprecated="false" show-location="false">
  A list of licenses associated with this person.

  **Example:**

  ```json
  "licenses": [{"type": "TREC", "value": "123456"}]
  ```

  <Expandable title="Sub-fields" default-open="false">
    <ParamField body="licenses.type" param-type="text" required="false" deprecated="false" show-location="false">
      The type of license the person value is identified by.
    </ParamField>

    <ParamField body="licenses.value" param-type="text" required="false" deprecated="false" show-location="false">
      The string value of the license identified by the type.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="maxListingPrice" param-type="float" required="false" deprecated="false" show-location="false">
  The maximum listing price among the broker's active property listings.

  **Example:**

  ```json
  "maxListingPrice": 895000
  ```
</ParamField>

<ParamField body="maxRecentSoldPrice" param-type="float" required="false" deprecated="false" show-location="false">
  The maximum most recently sold price of a property from the broker.

  **Example:**

  ```json
  "maxRecentSoldPrice": 700000
  ```
</ParamField>

<ParamField body="minListingPrice" param-type="float" required="false" deprecated="false" show-location="false">
  The minimum listing price among the broker's active property listings.

  **Example:**

  ```json
  "minListingPrice": 69000
  ```
</ParamField>

<ParamField body="minRecentSoldPrice" param-type="float" required="false" deprecated="false" show-location="false">
  The minimum most recently sold price of a property from the broker.

  **Example:**

  ```json
  "minRecentSoldPrice": 155000
  ```
</ParamField>

<ParamField body="propertiesRepresented" param-type="keyword" required="false" deprecated="false" show-location="false">
  The property the person represents as a broker. Links directly to a key within our property data.

  **Example:**

  ```json
  "propertiesRepresented": ["us/ut/ogden/668w4150s"]
  ```
</ParamField>

<ParamField body="recentlySoldCount" param-type="integer" required="false" deprecated="false" show-location="false">
  The number of recently sold properties associated with the broker.

  **Example:**

  ```json
  "recentlySoldCount": 32
  ```
</ParamField>

<ParamField body="salesCountAllTime" param-type="integer" required="false" deprecated="false" show-location="false">
  The total count of properties sold by the broker.

  **Example:**

  ```json
  "salesCountAllTime": 55
  ```
</ParamField>

<ParamField body="salesCountLastYear" param-type="integer" required="false" deprecated="false" show-location="false">
  The total count of properties sold by the broker within the last 365 days.

  **Example:**

  ```json
  "salesCountLastYear": 12
  ```
</ParamField>

<ParamField body="salesHistoryDateSeen" param-type="date" required="false" deprecated="false" show-location="false">
  The most recent date the broker's sales history was seen by Datafiniti.

  **Example:**

  ```json
  "salesHistoryDateSeen": "2026-09-06T16:02:39.028Z"
  ```
</ParamField>

## Contact Fields

<ParamField body="emails" param-type="text" required="false" deprecated="false" show-location="false">
  A list of emails associated with this person.

  **Example:**

  ```json
  "emails": ["doug@idronline.net"]
  ```
</ParamField>

<ParamField body="personalEmails" param-type="text" required="false" deprecated="false" show-location="false">
  The personal email addresses of the person.

  **Example:**

  ```json
  "personalEmails": ["mesheldo@gmail.com"]
  ```
</ParamField>

<ParamField body="phoneNumberHighScoreLand" param-type="text" required="false" deprecated="false" show-location="false">
  The highest reachable score (how likely the person is to pick up the phone) of the most recent landline phone from the phoneNumbers field.

  **Example:**

  ```json
  "phoneNumberHighScoreLand": "+1 440-238-1444"
  ```
</ParamField>

<ParamField body="phoneNumberHighScoreLandScore" param-type="integer" required="false" deprecated="false" show-location="false">
  The highest reachable score (how likely the person is to pick up the phone) amount of a landline phone from the phoneNumbers field.

  **Example:**

  ```json
  "phoneNumberHighScoreLandScore": 100
  ```
</ParamField>

<ParamField body="phoneNumberHighScoreMobile" param-type="text" required="false" deprecated="false" show-location="false">
  The highest reachable score (how likely the person is to pick up the phone) of the most recent mobile phone from the phoneNumbers field.

  **Example:**

  ```json
  "phoneNumberHighScoreMobile": "+1 602-571-8454"
  ```
</ParamField>

<ParamField body="phoneNumberHighScoreMobileScore" param-type="integer" required="false" deprecated="false" show-location="false">
  The highest score amount (how likely the person is to pick up the phone) of the most recent mobile phone from the phoneNumbers field.

  **Example:**

  ```json
  "phoneNumberHighScoreMobileScore": 90
  ```
</ParamField>

<ParamField body="phoneNumbers" param-type="nested" required="false" deprecated="false" show-location="false">
  A list of verified phone numbers where this person can be reached.

  **Example:**

  ```json
  {
    "number": "+1 205-665-7871",
    "carrier": "BELLSOUTH TELECOMM INC DBA SOUTH CENTRAL BELL TEL",
    "type": "Land Line",
    "tested": false,
    "reachableStatus": false,
    "bdscore": 70,
    "lastDateSeen": "2024-04-11T18:37:01.725Z"
  }
  ```

  <Expandable title="Sub-fields" default-open="false">
    <ParamField body="phoneNumbers.bdscore" param-type="float" required="false" deprecated="false" show-location="false">
      0-100 (higher the better) score on how likely the person is to pick up the phone.
    </ParamField>

    <ParamField body="phoneNumbers.carrier" param-type="text" required="false" deprecated="false" show-location="false">
      Carrier of the phone number.
    </ParamField>

    <ParamField body="phoneNumbers.lastDateSeen" param-type="date" required="false" deprecated="false" show-location="false">
      Last date seen of the phone number.
    </ParamField>

    <ParamField body="phoneNumbers.number" param-type="text" required="false" deprecated="false" show-location="false">
      The 10 digit plus country code phone number.
    </ParamField>

    <ParamField body="phoneNumbers.reachableStatus" param-type="boolean" required="false" deprecated="false" show-location="false">
      If the person was reachable on this phone number.
    </ParamField>

    <ParamField body="phoneNumbers.tested" param-type="boolean" required="false" deprecated="false" show-location="false">
      Tested status of the phone.
    </ParamField>

    <ParamField body="phoneNumbers.type" param-type="text" required="false" deprecated="false" show-location="false">
      Land line or mobile phone.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="primaryEmail" param-type="text" required="false" deprecated="false" show-location="false">
  The person's current professional email address.

  **Example:**

  ```json
  "primaryEmail": "maggie.sheldon@hover.to"
  ```
</ParamField>

<ParamField body="professionalEmails" param-type="text" required="false" deprecated="false" show-location="false">
  The person's professional email addresses.

  **Example:**

  ```json
  "professionalEmails": ["maggie.sheldon@hover.to", "msheldon@mavenlink.com"]
  ```
</ParamField>

</ParamField>

<ParamField body="dateOfDeath" param-type="date" required="false" deprecated="false" show-location="false">


<ParamField body="deceased" param-type="boolean" required="false" deprecated="false" show-location="false">

## Professional & Employment Fields

<ParamField body="businessCategories" param-type="text" required="false" deprecated="false" show-location="false">
  A list of category keywords used for the business the person currently works in. Business Categories for people data can be found [here](/docs/possible-values-for-people-fields).

  **Example:**

  ```json
  "businessCategories": ["Advertising Agencies"]
  ```
</ParamField>

<ParamField body="businessName" param-type="text" required="false" deprecated="false" show-location="false">
  The current business where this person works.

  **Example:**

  ```json
  "businessName": "International Direct Response Inc"
  ```
</ParamField>

<ParamField body="experiences" param-type="nested" required="false" deprecated="false" show-location="false">
  A list of the person's employment experiences. Each experience contains:

  **Example:**

  ```json
  "experiences": [
      {
        "jobTitle": "commercial mortgage underwriting intern",
        "jobLevel": "training",
        "businessName": "principal financial group",
        "numEmployeesMin": 10001,
        "numEmployeesMax": 10001,
        "address": "711 high street",
        "city": "des moines",
        "province": "iowa",
        "country": "united states",
        "latitude": "41.60,-93.60",
        "websites": ["principal.com"],
        "companyFounded": "1879"
      }
    ]
  ```

  <Expandable title="Sub-fields" default-open="false">
    <ParamField body="experiences.address" param-type="text" required="false" deprecated="false" show-location="false">
      The street address of the business for this experience.
    </ParamField>

    <ParamField body="experiences.businessName" param-type="text" required="false" deprecated="false" show-location="false">
      The name of the business for this experience.
    </ParamField>

    <ParamField body="experiences.city" param-type="text" required="false" deprecated="false" show-location="false">
      The city of the business for this experience.
    </ParamField>

    <ParamField body="experiences.companyFounded" param-type="text" required="false" deprecated="false" show-location="false">
      The year the business was founded.
    </ParamField>

    <ParamField body="experiences.country" param-type="text" required="false" deprecated="false" show-location="false">
      The country of the business for this experience.
    </ParamField>

    <ParamField body="experiences.jobLevel" param-type="text" required="false" deprecated="false" show-location="false">
      The job level held in this experience.
    </ParamField>

    <ParamField body="experiences.jobTitle" param-type="text" required="false" deprecated="false" show-location="false">
      The job title held in this experience.
    </ParamField>

    <ParamField body="experiences.latitude" param-type="text" required="false" deprecated="false" show-location="false">
      The latitude and longitude coordinates of the business, as a comma-separated string.
    </ParamField>

    <ParamField body="experiences.numEmployeesMax" param-type="integer" required="false" deprecated="false" show-location="false">
      The maximum number of employees at the business for this experience.
    </ParamField>

    <ParamField body="experiences.numEmployeesMin" param-type="integer" required="false" deprecated="false" show-location="false">
      The minimum number of employees at the business for this experience.
    </ParamField>

    <ParamField body="experiences.province" param-type="text" required="false" deprecated="false" show-location="false">
      The province/state of the business for this experience.
    </ParamField>

    <ParamField body="experiences.websites" param-type="text" required="false" deprecated="false" show-location="false">
      A list of websites associated with the business for this experience.
    </ParamField>
  </Expandable>
</ParamField>

## Property & Asset Fields

<ParamField body="mostRecentPropertyPurchaseDate" param-type="date" required="false" deprecated="false" show-location="false">
  The purchase date of the most recent property in relation to this person.

  **Example:**

  ```json
  "mostRecentPropertyPurchaseDate": "2024-12-04T00:00:00.000Z"
  ```
</ParamField>

<ParamField body="mostRecentPropertyPurchaseKey" param-type="keyword" required="false" deprecated="false" show-location="false">
  The most recent matching property key to the Datafiniti property database. Typically the currently owned property in regards to this person.

  **Example:**

  ```json
  "mostRecentPropertyPurchaseKey": "us/az/phoenix/3327n18thave"
  ```
</ParamField>

<ParamField body="propertiesOwned" param-type="text" required="false" deprecated="true" show-location="false">
  This field shows the property keys the person is connected to in Datafiniti's property database.

  Deprecated as of Jan 8th, 2026.

  **Example:**

  ```json
  "propertiesOwned": ["us/or/sisters/68885hurtleyrnchrd"]
  ```
</ParamField>

<ParamField body="propertiesOwnedHistory" param-type="nested" required="false" deprecated="false" show-location="false">
  A list of properties owned by this person with purchase and sale dates.

  **Example:**

  ```json
  [
    {
      "propertyKey": "us/az/phoenix/3327n18thave",
      "datePurchased": "2024-12-04T00:00:00.000Z"
    },
    {
      "propertyKey": "us/az/phoenix/3327n18thave",
      "dateSold": "2024-12-04T00:00:00.000Z",
      "datePurchased": "2024-12-04T00:00:00.000Z"
    }
  ]
  ```

  <Expandable title="Sub-fields" default-open="false">
    <ParamField body="propertiesOwnedHistory.datePurchased" param-type="date" required="false" deprecated="false" show-location="false">
      The date the homeowner purchased the property.
    </ParamField>

    <ParamField body="propertiesOwnedHistory.dateSold" param-type="date" required="false" deprecated="false" show-location="false">
      The date the property owner sold this property.
    </ParamField>

    <ParamField body="propertiesOwnedHistory.propertyKey" param-type="keyword" required="false" deprecated="false" show-location="false">
      The property data record that corresponds to the homeowner.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="propertyKeys" param-type="string" required="false" deprecated="false" show-location="false">
  The generated key from Datafiniti's property data. This key directly links a property to the person. Whether that be the broker or the owner of the property itself.

  **Example:**

  ```json
  "propertyKeys": ["us/tx/sugarland/72grantslkcir"]
  ```
</ParamField>
