---
title: Product Data Schema
---

The product data schema below lists all available fields in a product record. Note that actual product records may not have every field present.

## Availability Fields

<ParamField body="mostRecentPriceAvailability" param-type="text" required="false" deprecated="false" show-location="false">
  The product's most recent price availability scraped.

  **Example:**

  ```json
  "mostRecentPriceAvailability": "true"
  ```
</ParamField>

<ParamField body="quantities" param-type="nested" required="false" deprecated="false" show-location="false">
  A list of available quantities for this product. Quantities indicate how many units of the product are available from a specific source at a given time.

  Quantity objects may contain:

  **Example:**

  ```json
  "quantities": [
    {
      "dateSeen": [
        "2013-06-02T16:00:00Z",
        "2014-05-01T14:00:00Z"
      ],
      "sourceURLs": [
        "http://www.website.com/4567"
      ],
      "value": 20
    }
  ]
  ```

  **Sub-fields**

  `quantities.dateSeen` date

  A list of dates when this quantity was seen.

  `quantities.sourceURLs` keyword

  A list of URLs where this quantity was seen.

  `quantities.value` text

  The actual quantity value.
</ParamField>

## Classification Fields

<ParamField body="categories" param-type="text" required="false" deprecated="false" show-location="false">
  A list of category keywords used for this product across multiple sources.

  **Example:**

  ```json
  "categories": [
    "Home Improvement",
    "Heating, Cooling, & Air Quality",
    "Heaters",
    "Propane Heaters"
  ]
  ```
</ParamField>

<ParamField body="primaryCategories" param-type="text" required="false" deprecated="false" show-location="false">
  A list of standardized categories to which this product belongs. Category values can be found in the possible values documentation.

  **Example:**

  ```json
  "primaryCategories": [
    "Electronics"
  ]
  ```
</ParamField>

<ParamField body="secondaryCategories" param-type="text" required="false" deprecated="false" show-location="false">
  A list of second level standardized categories to which this product belongs.

  **Example:**

  ```json
  "secondaryCategories": [
    "Cell Phones"
  ]
  ```
</ParamField>

## Financing Fields

<ParamField body="financingAndLeasing" param-type="text" required="false" deprecated="false" show-location="false">
  A list of financing or leasing terms associated with this product. Each term may contain:

  **Example:**

  ```json
  "financingAndLeasing": [
    {
      "additionalDetails": [
        "acquisitionFee: $925",
        "mileOverageFee: $0.30/mile"
      ],
      "apr": 4.15,
      "currency": "USD",
      "dateSeen": [
        "2018-09-20T04:00:00Z"
      ],
      "description": "Well equipped with features",
      "disclaimers": "Offer not valid in Puerto Rico. Lease financing available",
      "dueAtSigningMax": 7694,
      "dueAtSigningMin": 7694,
      "milesPerYear": 22500,
      "monthlyPaymentMax": 1269,
      "monthlyPaymentMin": 1269,
      "name": "2018 Civic Si Coupe 6 Speed Manual Featured Special Lease",
      "offerStartDate": "2018-10-31T00:00:00.000Z",
      "offerEndDate": "2018-09-05T00:00:00.000Z",
      "term": "36 months",
      "type": "leasing",
      "securityDepositMax": 0,
      "securityDepositMin": 0,
      "sourceURLs": []
    }
  ]
  ```

  **Sub-fields**

  `financingAndLeasing.additionalDetails` text

  Any additional information related to this term.

  `financingAndLeasing.apr` text

  The annual percentage rate.

  `financingAndLeasing.currency` keyword

  The currency listed for any monetary values.

  `financingAndLeasing.dateSeen` date

  A list of dates when this term was seen.

  `financingAndLeasing.description` text

  The description provided for this term.

  `financingAndLeasing.disclaimers` text

  Any disclaimers associated with this term.

  `financingAndLeasing.dueAtSigningMax` float

  The maximum monetary amount due when purchasing this product under this term.

  `financingAndLeasing.dueAtSigningMin` float

  The minimum monetary amount due when purchasing this product under this term.

  `financingAndLeasing.milesPerYear` float

  Usually associated with vehicles, the maximum mileage allowed under this term.

  `financingAndLeasing.monthlyPaymentMax` float

  The maximum amount due each month under this term.

  `financingAndLeasing.monthlyPaymentMin` float

  The minimum amount due each month under this term.

  `financingAndLeasing.name` text

  The name for this term.

  `financingAndLeasing.type` keyword

  Either `financing` or `leasing`.

  `financingAndLeasing.securityDepositMax` float

  The maximum security deposit for this term.

  `financingAndLeasing.securityDepositMin` float

  The minimum security deposit for this term.

  `financingAndLeasing.sourceURLs` keyword

  A list of URLs where this term was seen.
</ParamField>

## Generic Fields

<ParamField body="dateAdded" param-type="date" required="false" deprecated="false" show-location="false">
  The date this product was first added to the product database.

  **Example:**

  ```json
  "dateAdded": "2017-01-08T19:12:13Z"
  ```
</ParamField>

<ParamField body="dateUpdated" param-type="date" required="false" deprecated="false" show-location="false">
  The most recent date this product was updated or seen by our system.

  **Example:**

  ```json
  "dateUpdated": "2017-01-08T19:12:13Z"
  ```
</ParamField>

<ParamField body="descriptions" param-type="nested" required="false" deprecated="false" show-location="false">
  A list of descriptions for this product from various sources. Each description contains:

  **Example:**

  ```json
  "descriptions": [
    {
      "dateSeen": "2017-01-08T19:12:13Z",
      "sourceURLs": [
        "https://www.domain.com/p/123"
      ],
      "value": "Now you can enjoy cooking your favorite food."
    },
    {
      "sourceURLs": [
        "http://www.website.com/4567"
      ],
      "value": "The Worthington Pro Grade 20 lb. Empty Propane Tank goes with your gas barbecue grill (sold separately) and accommodates 4.7 gallons of gas."
    }
  ]
  ```

  **Sub-fields**

  `descriptions.dateSeen` date

  The date when this description has been seen selling this product.

  `descriptions.sourceURLs` keyword

  A list of source URLs where this specific description was seen.

  `descriptions.value` text

  A unique description for this product.
</ParamField>

<ParamField body="features" param-type="nested" required="false" deprecated="false" show-location="false">
  A list of features associated with this product. The feature list can be collected from specific feature sections available on product listings for the product. It can also serve as a catch-all field for miscellaneous characteristics of this product that don't make sense to include as top-level fields.

  Each feature contains:

  **Example:**

  ```json
  "features": [
    {
      "key": "Count",
      "replace": "true",
      "value": [
        "1"
      ]
    },
    {
      "key": "Included",
      "value": [
        "Batteries"
      ]
    }
  ]
  ```

  **Sub-fields**

  `features.key` text

  A label for this feature.

  `features.replace` boolean

  Flag indicating value field is replaced versus appended.

  `features.value` text

  A list of possible values for this feature.
</ParamField>

<ParamField body="keys" param-type="keyword" required="false" deprecated="false" show-location="false">
  A list of internal Datafiniti identifiers for this product. The `keys` field is used to merge raw data from individual sources into the master Datafiniti record.

  **Example:**

  ```json
  "keys": [
    "014045125963",
    "0014045125963",
    "worthington/299581"
  ]
  ```
</ParamField>

## Merchant Fields

<ParamField body="merchants" param-type="nested" required="false" deprecated="false" show-location="false">
  A list of merchants selling this product. These are typically third-party merchants found on e-commerce websites.

  Merchant objects can contain:

  **Example:**

  ```json
  "merchants": [
    {
      "address": "2801 S Ih 35",
      "availability": "...",
      "city": "Austin",
      "country": "US",
      "dateSeen": "2017-01-08T19:12:13Z",
      "isPrivateSeller": false,
      "name": "Zappysales",
      "phone": "5127131234",
      "postalCode": "78701",
      "province": "TX"
    },
    {
      "dateSeen": [
        "2017-01-08T19:12:13Z"
      ],
      "name": "Next Day Mro, Llc"
    }
  ]
  ```

  **Sub-fields**

  `merchants.address` text

  The merchant's physical address.

  `merchants.availability` keyword

  A description of the product's availability with this merchant.

  `merchants.city` text

  The merchant's city.

  `merchants.dateSeen` date

  The date when this merchant has been seen selling this product.

  `merchants.isPrivateSeller` boolean

  True if the merchant is an individual. False if it's a company.

  `merchants.name` text

  The merchant's name.

  `merchants.phone` keyword

  The merchant's phone number.

  `merchants.postalCode` text

  The merchant's postal or zip code.

  `merchants.province` text

  The merchant's province or state.
</ParamField>

## Pricing Fields

<ParamField body="mostRecentPriceAmount" param-type="float" required="false" deprecated="false" show-location="false">
  The product's most recent price amount scraped.

  **Example:**

  ```json
  "mostRecentPriceAmount": 85
  ```
</ParamField>

<ParamField body="mostRecentPriceCurrency" param-type="text" required="false" deprecated="false" show-location="false">
  The currency listed for mostRecentPriceAmount.

  **Example:**

  ```json
  "mostRecentPriceCurrency": "USD"
  ```
</ParamField>

<ParamField body="mostRecentPriceDate" param-type="date" required="false" deprecated="false" show-location="false">
  The most recent price date of the product record.

  **Example:**

  ```json
  "mostRecentPriceDate": "2022-03-29T19:26:49.157Z"
  ```
</ParamField>

<ParamField body="prices" param-type="nested" required="false" deprecated="false" show-location="false">
  A list of prices for this product.

  Price objects may contain:

  **Example:**

  ```json
  "prices": [
    {
      "amountMin": 59.96,
      "amountMax": 59.96,
      "availability": "true",
      "color": "Red",
      "condition": "New",
      "count": "15",
      "currency": "USD",
      "dateSeen": [
        "2016-06-10T00:00:00Z"
      ],
      "flavor": "Cherry",
      "isSale": "false",
      "isSold": "false",
      "merchant": "domain.com",
      "offer": "22% off",
      "returnPolicy": "90-Day",
      "shipping": "FREE shipping",
      "size": "S",
      "sourceURLs": [
        "https://www.domain.com/p/123"
      ],
      "warranty": "..."
    },
    {
      "amountMin": 62.06,
      "amountMax": 72.06,
      "condition": "new",
      "currency": "USD",
      "dateSeen": [
        "2016-10-28T00:00:00Z"
      ],
      "merchant": "MRO - website.com",
      "sourceURLs": [
        "http://www.website.com/4567"
      ]
    }
  ]
  ```

  **Sub-fields**

  `prices.amountMin` float

  The minimum price value listed.

  `prices.amountMax` float

  The maximum price value listed. This is typically the same as amountMin, except in cases where a price range is listed.

  `prices.availability` keyword

  A true or false if this product is available at this price.

  `prices.color` keyword

  The color associated with this price.

  `prices.condition` keyword

  The condition of the product when being sold at this price.

  `prices.count` keyword

  The number of units being sold at this price.

  `prices.currency` text

  The currency listed for amountMin and amountMax.

  `prices.dateSeen` date

  A list of dates when this price was seen.

  `prices.flavor` keyword

  The flavor associated with this price.

  `prices.isSale` boolean

  A true/false for whether or not this price is a sale/discounted price.

  `prices.isSold` boolean

  A true/false for whether or not the product has been sold at this price, typically reserved for vehicle listings.

  `prices.merchant` keyword

  The merchant and/or website selling at this price.

  `prices.offer` text

  Any special offer associated with this price.

  `prices.returnPolicy` text

  The return policy associated with this price.

  `prices.shipping` text

  The shipping terms associated with this price.

  `prices.size` text

  The size associated with this price.

  `prices.sourceURLs` keyword

  A list of URLs where this price was seen.

  `prices.warranty` text

  The warranty associated with this price.
</ParamField>

## Product Identifier Fields

<ParamField body="asins" param-type="keyword" required="false" deprecated="false" show-location="false">
  The ASIN (Amazon identifier) used for this product.

  **Example:**

  ```json
  "asins": "B0009XCFRE"
  ```
</ParamField>

<ParamField body="ean" param-type="keyword" required="false" deprecated="false" show-location="false">
  The EAN codes for this product. There may be more than one EAN in the list when a product has multiple variations, each using a different EAN.

  **Example:**

  ```json
  "ean": [
    "0014045125963",
    "0014045125965"
  ]
  ```
</ParamField>

<ParamField body="ean13" param-type="keyword" required="false" deprecated="false" show-location="false">
  The EAN-13 code for this product.

  **Example:**

  ```json
  "ean13": "0014045125963"
  ```
</ParamField>

<ParamField body="ean8" param-type="keyword" required="false" deprecated="false" show-location="false">
  The EAN-8 code for this product.

  **Example:**

  ```json
  "ean8": "96385074"
  ```
</ParamField>

<ParamField body="gtins" param-type="keyword" required="false" deprecated="false" show-location="false">
  A list of all Global Trade Identifier Numbers for this product. Values will include all ean, isbn, and upc values.

  **Example:**

  ```json
  "gtins": [
    "0014045125963",
    "0014045125965",
    "014045125963",
  ```

</ParamField>

<ParamField body="isbn" param-type="keyword" required="false" deprecated="false" show-location="false">
  The ISBN code for this product.

  ```json
  "isbn": "3882215542"
  ```
</ParamField>

<ParamField body="manufacturerNumber" param-type="keyword" required="false" deprecated="false" show-location="false">
  The manufacturer or model number of this product.

  **Example:**

  ```json
  "manufacturerNumber": "299581"
  ```
</ParamField>

<ParamField body="skus" param-type="nested" required="false" deprecated="false" show-location="false">

  **Example:**

<ParamField body="upc" param-type="keyword" required="false" deprecated="false" show-location="false">

  **Example:**

  ```json
  "upc": [
    "014045125963",
    "014045125961"
  ]
  ```

<ParamField body="upca" param-type="keyword" required="false" deprecated="false" show-location="false">

  **Example:**

<ParamField body="upce" param-type="keyword" required="false" deprecated="false" show-location="false">

## Review Fields

<ParamField body="reviews" param-type="nested" required="false" deprecated="false" show-location="false">
  A list of reviews for this product.

  Review objects may contain:

  **Example:**

  ```json
  "reviews": [
    {
      "date": "2015-06-16T00:00:00Z",
      "dateSeen": "2016-05-15T00:00:00Z",
      "didPurchase": true,
      "doRecommend": true,
      "id": "1234",
      "numHelpful": 4,
      "rating": 4,
      "sourceURLs": [
        "http://www.website.com/4567"
      ],
      "text": "Nice tank at a below average cost for propane tanks.",
      "title": "Solid Propane Tank",
      "userCity": "...",
      "username": "Cole33",
      "userProvince": "..."
    },
    {
      "date": "2015-01-06T00:00:00Z",
      "dateSeen": [
        "2016-05-15T00:00:00Z"
      ],
      "rating": 5,
      "sourceURLs": [
        "https://www.domain.com/p/123"
      ],
      "text": "Holds propane and does not leak. Completed the given gift.",
      "title": "tanked",
      "username": "joel01"
    }
  ]
  ```

  **Sub-fields**

  `reviews.date` date

  The date the review was posted.

  `reviews.dateSeen` date

  The date when the review was seen by Datafiniti.

  `reviews.didPurchase` boolean

  A true/false for whether or not the reviewer did purchase the product.

  `reviews.doRecommend` boolean

  A true/false for whether or not the reviewer recommends the product.

  `reviews.id` keyword

  The website ID associated with this review.

  `reviews.numHelpful` integer

  The number of people that found this review helpful.

  `reviews.rating` float

  A 1 to 5 star value for the review.

  `reviews.sourceURLs` keyword

  A list of URLs where this review was seen.

  `reviews.text` text

  The full (or available) text of the review.

  `reviews.title` text

  The review's title.

  `reviews.userCity` text

  The reviewer's city.

  `reviews.username` text

  The reviewer's username.

  `reviews.userProvince` text

  The reviewer's province or state.
</ParamField>

  A true/false for whether or not this price is a sale/discounted price.

  `mostRecentPriceByDomain.size` text

  `mostRecentPriceByDomain.sourceURLs` text
