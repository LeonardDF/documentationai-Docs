## Geographical Details

The property data schema below lists all available fields in a property record. Actual property records may not include every field.

<ParamField showLocation="false" body="address" param-type="text">
  The physical street address for this property.

  **Example:**

  ```json
  "address": "7206 Walling Ln"
  ```
</ParamField>

<ParamField showLocation="false" body="buildingName" param-type="text">
  The name of the building where this property is located. This field is specific to apartments, condos, and similar property types.

  **Example:**

  ```json
  "buildingName": "Castle Beach Club"
  ```
</ParamField>

<ParamField showLocation="false" body="city" param-type="text">
  The city where the property is located.

  **Example:**

  ```json
  "city": "Dallas"
  ```
</ParamField>

<ParamField showLocation="false" body="country" param-type="text">
  The two-letter country code for the property location's country.

  **Example:**

  ```json
  "country": "US"
  ```
</ParamField>

<ParamField showLocation="false" body="county" param-type="text">
  The county of the property record.

  **Example:**

  ```json
  "county": "Hillsborough"
  ```
</ParamField>

<ParamField showLocation="false" body="geoLocation" param-type="geo_shape">
  A location value that stores the latitude and longitude in a format that allows geospatial querying.

  The value is stored as Well-Known Text format, which resembles an (x, y) value, i.e. (longitude latitude).

  **Example:**

  ```json
  "geoLocation": "POINT (-119.5094 37.229366)"
  ```
</ParamField>

<ParamField showLocation="false" body="geoQuality" param-type="integer">
  The quality of the geoLocation data of the property.

  **Example:**

  ```json
  "geoQuality": 0
  ```
</ParamField>

<ParamField showLocation="false" body="imageURLs" param-type="keyword">
  A list of image URLs for this property.

  **Example:**

  ```json
  "imageURLs": ["http://image.rent.com/imgr/61bbc9f535f0e180bc804ac8f4c50067"]
  ```
</ParamField>

<ParamField showLocation="false" body="latitude" param-type="text">
  The latitude coordinates for this property.

  **Example:**

  ```json
  "latitude": "32.860858"
  ```
</ParamField>

<ParamField showLocation="false" body="longitude" param-type="text">
  The longitude coordinates for this property.

  **Example:**

  ```json
  "longitude": "-96.735808"
  ```
</ParamField>

<ParamField showLocation="false" body="postalCode" param-type="keyword">
  The postal or zip code of the property.

  **Example:**

  ```json
  "postalCode": "75231"
  ```
</ParamField>

<ParamField showLocation="false" body="province" param-type="text">
  The province or state for this property.

  **Example:**

  ```json
  "province": "TX"
  ```
</ParamField>

<ParamField showLocation="false" body="title" param-type="text">
  The title text of the property.

  **Example:**

  ```json
  "title": "Single Family Residence, A-Frame - Snellville, GA"
  ```
</ParamField>

<ParamField showLocation="false" body="topographyCode" param-type="string">
  A code describing the landform or terrain classification for the property.

  **Example:**

  ```json
  "topographyCode": "LEVEL"
  ```
</ParamField>

## Broker Details

<ParamField showLocation="false" body="brokers" param-type="nested">
  A list of brokers associated with this property.

  **Example:**

  ```json
  "brokers": [
      {
        "name": "Rackel Atkins",
        "company": "Compass Recom",
        "dateSeen": "2023-10-23T19:20:50.418Z",
        "emails": ["mavhovsepia@pearsonrealty.com"],
        "phones": ["(713) 948-6666"]
      }
    ]
  ```
</ParamField>

<ParamField showLocation="false" body="listingName" param-type="text">
  The name of the property listing. This isn't the name of the building. It's a descriptive name supplied for the listing itself.

  **Example:**

  ```json

  ```
</ParamField>

<ParamField showLocation="false" body="mlsName" param-type="text">

  **Example:**


</ParamField>

<ParamField showLocation="false" body="mlsNumber" param-type="keyword">

  **Example:**


</ParamField>

<ParamField showLocation="false" body="mostRecentBrokerAgent" param-type="text">

<ParamField showLocation="false" body="mostRecentBrokerDateSeen" param-type="text">

<ParamField showLocation="false" body="mostRecentBrokerEmails" param-type="text">

  **Example:**

  ```json
  "mostRecentBrokerEmails": ["mavhovsepia@pearsonrealty.com"]
  ```

<ParamField showLocation="false" body="mostRecentBrokerPhones" param-type="text">

  **Example:**

  ```json
  "mostRecentBrokerPhones": ["(713) 948-6666"]
  ```

## Pricing Details

<ParamField showLocation="false" body="deposits" param-type="nested">
  A list of deposit fees that have been seen for this property. Each deposit contains:

  **Example:**

  ```json

        "amount": 104,
        "currency": "USD",
        "dateSeen": [
          "2016-08-07T18:07:05Z"
        ]
      }
    ]
  ```

      The fee amount.
    </ParamField>

    </ParamField>

    <ParamField showLocation="false" body="deposits.dateSeen" param-type="date">

  </Expandable>
