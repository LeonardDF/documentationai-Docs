## Broker Fields

<ParamField body="brokers" param-type="nested" showLocation="false">
  A list of brokers associated with this property.

  **Example:**

  ```json
  "brokers": [
      {
        "name": "Rackel Atkins",
        "company": "Compass Recom",
        "dateSeen": "2023-10-23T19:20:50.418Z",
        "emails": ["mavhovsepia@pearsonrealty.com"],
        "phones": ["(713) 948-6666"]
      }
    ]
  ```
</ParamField>

<ParamField body="mlsNumber" param-type="keyword" showLocation="false">
  The MLS number for the property. [Learn more about MLS numbers](https://en.wikipedia.org/wiki/Multiple_listing_service).

  **Example:**

  ```json
  "mlsNumber": "16177277"
  ```
</ParamField>

<ParamField body="mostRecentBrokerAgent" param-type="text" showLocation="false">
  The most recent broker agent added to the brokers field.

  **Example:**

  ```json
  "mostRecentBrokerAgent": "Rackel Atkins"
  ```
</ParamField>

<ParamField body="mostRecentBrokerCompany" param-type="text" showLocation="false">
  The company of the most recent broker added to the broker's field.

  **Example:**

  ```json
  "mostRecentBrokerCompany": "Compass Recom"
  ```
</ParamField>

<ParamField body="mostRecentBrokerDateSeen" param-type="text" showLocation="false">

  **Example:**

  ```json
  "mostRecentBrokerDateSeen": "2023-10-23T19:20:50.418Z"
  ```
</ParamField>

<ParamField body="mostRecentBrokerEmails" param-type="text" showLocation="false">
  The email(s) of the most recent broker agent.

  **Example:**

  ```json
  "mostRecentBrokerEmails": ["mavhovsepia@pearsonrealty.com"]
  ```
</ParamField>

<ParamField body="mostRecentBrokerPhones" param-type="text" showLocation="false">
  The phone number(s) of the most recent broker agent.

  **Example:**

  ```json
  "mostRecentBrokerPhones": ["(713) 948-6666"]
  ```
</ParamField>

## Estimated Price Fields

<ParamField body="estimatedPrices" param-type="nested" showLocation="false">
  A list of price estimates for the property.

  **Example:**

  ```json
  "estimatedPrices": [
      {
        "amountMax": 295000,
        "amountMin": 295000,
        "currency": "USD",
        "dateSeen": [
          "2023-10-20T16:53:37.235Z"
        ],
        "pricePerSquareFoot": 112.51
      }
    ]
  ```

  <Expandable title="Sub-fields" default-open="false">
    <ParamField body="estimatedPrices.amountMax" param-type="integer" showLocation="false">
      The maximum price estimate value listed.
    </ParamField>

    <ParamField body="estimatedPrices.amountMin" param-type="integer" showLocation="false">
      The minimum price estimate value listed.
    </ParamField>

    <ParamField body="estimatedPrices.currency" param-type="string" showLocation="false">
      The currency listed for amountMin and amountMax
    </ParamField>

    <ParamField body="estimatedPrices.dateSeen" param-type="date" showLocation="false">
      The date when this estimatedPrice was seen for this property.
    </ParamField>

    <ParamField body="estimatedPrices.pricePerSquareFoot" param-type="float" showLocation="false">
      The price divide by the square footage.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="mostRecentEstimatedPriceAmount" param-type="integer" showLocation="false">
  The most recent estimated price amount

  **Example:**

  ```json

  ```
</ParamField>

<ParamField body="mostRecentEstimatedPriceDate" param-type="date" showLocation="false">

  **Example:**

  ```json
  "mostRecentEstimatedPriceDate": "2024-09-11T00:00:00.000Z"
  ```
</ParamField>

<ParamField body="mostRecentEstimatedPriceDomain" param-type="text" showLocation="false">

  **Example:**

