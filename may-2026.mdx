## May 2026 release log

We’ve launched a completely redesigned version of the Datafiniti Documentation Website.

This update focuses on making it easier to learn, build, and troubleshoot with Datafiniti’s APIs and portal. Alongside a full visual overhaul, we’ve introduced new tools directly into the documentation to help streamline your workflow and reduce friction when working with our data.

In addition, our previous recipe cards and integration examples have been migrated to our public GitHub repository. These resources are now available to both paid and free trial users, making it easier to explore real-world use cases and implementation patterns.

### Built-In AI Assistant

The new documentation now includes a built-in AI assistant designed specifically for Datafiniti users.

`AiAssistant` is optimized to help you:

- Understand how to structure API queries
- Perform in-depth analysis of the Property, People, Product, and Business data schemas
- Translate natural language into valid API requests
- Troubleshoot issues with queries and responses

Because it is tailored to Datafiniti’s API, it can provide more relevant and accurate guidance than general-purpose AI tools.

### Visual redesign

The documentation site has been fully redesigned to improve usability and navigation.

Updates include:

- A cleaner, more modern layout
- Improved organization of endpoints and guides
- Enhanced readability for technical documentation
- More consistent and accessible code examples

These changes are intended to make it faster to locate relevant information and reduce the time spent navigating between pages.

### API Status Indicator

We’ve added a built-in API status page directly within the documentation.

This allows you to check quickly:

- Current system availability
- Active incidents or degraded performance
- Whether issues may be impacting your API requests

The indicator is connected to the Datafiniti Status Page, providing real-time visibility without leaving the documentation.

### Why This Matters

This release is focused on improving the overall developer experience when working with Datafiniti.

With these updates, you can:

- Get up to speed more quickly when onboarding
- Build and refine queries with greater confidence
- Reduce time spent troubleshooting
- Access critical system information in one place
- Leverage real-world examples directly from our public GitHub repository

### Developer Resources

We’ve moved our previous recipe cards and integration examples, which were originally created to supplement our old documentation, into a standalone public GitHub repository: Datafiniti Integrated Use Cases.

This dedicated resource is now easier to access, maintain, and provides practical, real-world examples of working with Datafiniti’s APIs.

These resources are available to both paid and free trial users.
