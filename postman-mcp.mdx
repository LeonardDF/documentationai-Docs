# Postman with Datafiniti's MCP

Postman is the easiest way to exercise Datafiniti before you wire up an agent. You can complete the MCP handshake, list the available tools and prompts, and call a tool by hand — or hit the REST API directly — all without writing any code. It's one of several ways to use Datafiniti with AI (see the [Overview](https://docs.datafiniti.co/overview)); this one is best for confirming things work and for building queries you'll hand to another tool.

For this guide we'll assume you want to confirm the MCP server is reachable with your token, see what tools and prompts are exposed, and run a single `df_search` to verify you get records back.

## 1. Download Postman

We recommend Postman for working with both the Datafiniti MCP server and the REST API. Download it [here](https://www.postman.com/downloads/).

<Callout kind="info" collapsed="false">
  **Postman version**

  MCP support is only in recent versions of Postman. If you don't see an MCP request type, update to the latest release.
</Callout>

## 2. Get your API token

You'll authenticate with the same bearer token as REST — there's no separate MCP credential. Get it from the [Datafiniti Web Portal](https://portal.datafiniti.co/settings/api), log in, and open settings from the left navigation bar.

**API Key**

For the rest of this page we'll use `AAAXXXXXXXXXXXX` as a stand-in for your real token.

<Callout kind="alert" collapsed="false">
  **API Key Regen**

  For security reasons, your API token is automatically changed whenever you change your password.
</Callout>

## 3. Create an MCP request

In Postman, create a new **MCP** request and set the server URL to:

```typescript
https://api.datafiniti.co/v4/mcp
```

Set the transport to **Streamable HTTP** — the transport the Datafiniti server uses.

<Image src="https://blob-cdn.documentation.ai/org-a829270c-4408-45aa-90cb-a8cad2967955/doc-82f0e261-4f6b-45af-9f00-b0b805bf07d2/1789761870246-fz8i0cnkxe6-MCPaddedgif.gif?fm=auto&auto=compress%2Cformat" width="1720" height="1000" alt="MCPaddedgif" />

_Screenshot: a new MCP request in Postman with the server URL and transport set._

## 4. Add your authorization

Under the request's **Authorization** tab, choose **Bearer Token** and paste your token:

```typescript
Authorization: Bearer AAAXXXXXXXXXXXX
```

Your token tells the server who you are, what you have access to, and how to account for credits — exactly as for a REST call. Field permissions are enforced identically to REST.

<Image src="https://blob-cdn.documentation.ai/org-a829270c-4408-45aa-90cb-a8cad2967955/doc-82f0e261-4f6b-45af-9f00-b0b805bf07d2/1789740593097-ox2qvuutez-postmanMCPAuth.png?fm=auto&auto=compress%2Cformat" width="1369" height="544" alt="postmanMCPAuth" />

_Screenshot: the Authorization tab set to Bearer Token._

## 5. Connect and list tools

Send the request to connect. Postman performs the MCP handshake, then lets you list what the server exposes:

```typescript
df_search
df_count
df_start_download
df_download_status
df_get_record
df_get_schema
```

<Image src="https://blob-cdn.documentation.ai/org-a829270c-4408-45aa-90cb-a8cad2967955/doc-82f0e261-4f6b-45af-9f00-b0b805bf07d2/1789740688733-lsptika7h5-poostmanMCP_prompt.png?fm=auto&auto=compress%2Cformat" width="1366" height="660" alt="poostmanMCP prompt" />

_Screenshot: the connected server with the Datafiniti tools listed._

Each reuses the same REST request handler the public API uses, so behavior and pricing match REST exactly.

<Callout kind="tip" collapsed="false">
  **Handshake overlap**

  A single MCP handshake issues several requests in quick succession — `initialize`, `notifications/initialized`, `tools/list`, `prompts/list`, and an optional stream request. This is expected; the server's rate limit accounts for it.
</Callout>

## 6. List the prompts

List the available **prompts**. Each converts a `docs.datafiniti.co` use-case guide into a ready-to-run query template and returns a built query rather than executing anything itself.

Where a prompt argument has a small, verified value set (such as a property `status`), Postman renders it as a dropdown rather than a free-text box, because those arguments are defined as enums.

<Image src="https://blob-cdn.documentation.ai/org-a829270c-4408-45aa-90cb-a8cad2967955/doc-82f0e261-4f6b-45af-9f00-b0b805bf07d2/1789762181678-2k0zoynp804-pasted-image-propmts-postman.png?fm=auto&auto=compress%2Cformat" width="1363" height="930" alt="" />

<Callout kind="tip" collapsed="false">
  **Prompt arguments are flat strings**

  MCP prompt arguments are transmitted as a flat string-to-string map, so every argument is a simple string — no arrays or nested objects. Nested values use dot notation where needed.


</Callout>

## 7. Call a tool

Select `df_search` and provide its arguments. For a property search:

```typescript
{
  "query": "country:US AND propertyType:\"Single Family Dwelling\"",
  "num_records": 1
}
```

Send it. The server runs the same handler as REST `/search`, charges credits identically, and returns up to 50 records (here, 1). You'll get back `num_found`, `total_cost`, and a `records` array — the same shape a REST search returns.

<Image src="https://blob-cdn.documentation.ai/org-a829270c-4408-45aa-90cb-a8cad2967955/doc-82f0e261-4f6b-45af-9f00-b0b805bf07d2/1789762386512-azypctsxpat-df_search-Screenshot.png?fm=auto&auto=compress%2Cformat" width="1366" height="1225" alt="" />

<Callout kind="tip" collapsed="false">
  **Escaped quotes**

  Exact-match values inside a query use escaped quotes — `propertyType:\"Single Family Dwelling\"` — not unescaped quotes.
</Callout>

## 8. Read structured errors

If a call fails, the tools agents actually hit return a structured error object rather than a bare status code:

```typescript
{
  "code": "invalid_query",
  "message": "…",
  "field": "query"
}
```

Branch on the stable `code` — for example `invalid_query`, `invalid_view`, `out_of_range`, `credit_limit_exceeded`, or `no_results` — rather than string-matching the `message`. This is the same error shape your agent will see in production.

## Using the REST API in Postman instead

You don't have to use MCP at all. If you just want to build and run queries by hand — for example to develop a query you'll paste into a conversation with [Claude](https://docs.datafiniti.co/claude) — you can call the REST endpoints directly. Each data type's "…with Postman" page walks through the REST flow: see [Property Data with Postman](https://docs.datafiniti.co/docs/property-data-with-postman) and the equivalent pages for people, product, and business data.

## Next steps

Once the server responds and returns records, you're ready to point an AI client at the same endpoint and token. See [MCP Server](https://docs.datafiniti.co/mcp-server) for the full tool and prompt reference, and the per-data-type "…with AI" pages for fields, statuses, and prompts.
