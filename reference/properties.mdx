<Card title="Autotrace" href="/docs/autotrace-property" icon="link" horizontal="false">
  Learn how to use autotrace to combine property and people data.
</Card>

<Callout kind="info" collapsed="false">
  Autotrace property x people data only applies to records with people.title:owner populated. You will not receive any records until this people title is populated.
</Callout>

<Callout kind="alert" collapsed="false">
  Autotrace requires both a people and property data plan to work. One record returned will consume 1 people data and 1 property data credit. If you have questions about how this works please contact [support@datafiniti.co](mailto:support@datafiniti.co).
</Callout>

<Callout kind="alert" collapsed="false">
  The `num_records` parameter is **required** when requesting property data. If it is not included in your request, you will receive the error: `"should have required property 'num_records'"`.
</Callout>

<Callout kind="tip" collapsed="false">
  We recommend using the [count feature](/docs/count-property) first to determine the exact number of records available for your query. You can also set `num_records` to a higher number than expected — you will only be charged for the records you actually download, not the number you request.
</Callout>
